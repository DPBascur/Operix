# Aplicación Web

Componente de Operix Architecture v1.0 encargado de permitir la configuración de criterios operacionales, la consulta de eventos y la visualización de indicadores históricos mediante el Backend/API.

- Stack aprobado: Next.js + TypeScript.
- Comunicación con el Backend/API; sin acceso directo a PostgreSQL.
- Estado: implementación pendiente. Esta carpeta documenta la responsabilidad del componente.

Consulte el [índice de arquitectura](../docs/architecture/README.md) para los artefactos vigentes.
